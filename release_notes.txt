## What's New / 更新内容
- Updated Gemini image generation to the current Nano Banana 2-compatible `gemini-3.1-flash-image` model.
- Removed legacy Gemini preview/2.5 image model options from the app's image-generation selector.
- Aligned OpenAI image editing with current `gpt-image-2` settings: PNG output, high quality, MIME preservation, and a 600-second timeout.
- Synchronized app version metadata for v1.9.0.
