# AI漫画翻訳ツールでページを翻訳する

1. 原ページと訳先言語、ページ順・コマ順を確認する。読み方向から左右反転の目的を判断し、反転が利き手、看板や文字の向き、前後ページと矛盾しないかを見る。反転の要否を指定された場合はその選択を使う。
2. 画像化する前に、吹き出し単位で原文と訳文を対応させる。話者の口調、固有名詞、擬音や注記の扱いを揃える。翻訳文が収まらない場合は意味と口調を保って言い換え、抜けた台詞を創作で埋めない。
3. 翻訳画像を開き、吹き出しごとの訳・話者・読み順と、文字の欠け、線画・トーン・色の実害を確認する。部分修正は採用候補を基に直す範囲を限定する。訳漏れの広がりや画質劣化がある場合は、元ページへ戻ってやり直す経路を選ぶ。
4. 汎用プロンプトだけを求められた場合はキー不要の出力を使う。MCP利用時は接続先と実際のツール仕様を確認する。利用できなければ通常画面か原文・訳文の照合を進め、どこまで実施したかを伝える。

## MCPで原稿を引き継ぐ

1. 画面上部の制作スキル、MCP導入ガイド、操作マニュアル、API設定ガイドを使う。ローカル接続は comictranslate_capabilities で版・接続とAPI準備状況を確認する。
2. 採用した原稿を読み込み、原文と訳先の言語・反転設定を画面で確認する。画像選択時に自動抽出が走る場合は、その結果を先に読む。実行中の同じ抽出を重ねない。
3. comictranslate_process_page は extract、render_original、refine を選べる。固有の requestId で投入し、comictranslate_job_get で同じジョブを追う。extract の行を照合してから render_original を実行する。修正が必要なときだけ対象を限定して refine を使う。
4. 採用版の翻訳画像と原文・訳文の対応を保存する。PNGと対応する制作情報は、原本や別ページと取り違えない名前で管理する。
