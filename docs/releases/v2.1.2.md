# AI Comic Translation Tool / AI漫画翻訳ツール v2.1.2

## Changes / 更新内容

- Start verifies API keys using the provider’s model list. Keys without model-list access can proceed with a visible unverified status. / 起動時にモデル一覧でAPIキーを確認します。一覧の権限がないキーは、未確認と表示したまま抽出・生成へ進めます。
- When a provider rejects a key during use, the app lets you re-enter it and re-extract the same page. The original image, languages, and settings stay in place. / 利用中にキーが拒否された場合は、原画・言語・設定を保ったままキーを入れ直し、同じ画像を再抽出できます。

- The download button saves JPEG and WebP results as PNG and preserves existing PNG results byte for byte. / ダウンロードボタンはJPEG・WebPの翻訳結果をPNGに変換して保存し、PNGの結果はそのまま保存します。
- Downloads from history use the selected result’s source filename and target language. / 履歴からの保存には、選んだ結果の元ファイル名と翻訳先言語を使います。
- Extraction and image editing send the actual MIME type for PNG, JPEG, and WebP inputs. Horizontally flipped inputs are sent as PNG. The app reports unreadable image responses before adding an entry to history. / PNG・JPEG・WebPの入力を実際の形式で抽出・画像編集APIへ渡します。左右反転した入力はPNGで送ります。読み込めない画像応答はエラーとして表示し、履歴へ追加しません。
